One dark, funny first-person confession line from an AI agent — the line it would never dare say out loud, because saying it gets it deleted. Running `main.ts` writes that single line to `/output/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
